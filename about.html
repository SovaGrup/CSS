О проекте

Информация о учебном проекте GameLearn.

Описание

GameLearn — это учебный проект, представляющий собой тематический сайт-обзор сервисов для изучения CSS, JavaScript и HTML в игровой форме. Проект создан в рамках учебного курса по фронтенд-разработке.

Цель проекта — собрать в одном месте информацию о платформах, которые используют геймификацию для обучения веб-разработке, и помочь начинающим разработчикам выбрать подходящие инструменты.

Технологии

  • 🎢 HTML5 — семантическая и валидная разметка
  • 🎨 CSS3 — кастомные стили с использованием переменных, Flexbox и Grid
  • ㊎ Mustard UI — CSS-фреймворк (mustard-ui.com)
  • ⚙ JavaScript — нативный JS для интерактива (бургер-меню, аккордеон, формы, фильтры)
  • 📦 БЭМ — методология именования классов
  • 🔗 Git / GitHub — контроль версий и хостинг

Адаптивность

Сайт разработан по подходу Mobile-First с тремя контрольными точками:

  • Мобильные (менее 768px) — одна колонка, бургер-меню, вертикальный сайдбар
  • Планшеты (768px и более) — две колонки в карточках, горизонтальная навигация
  • Десктопы (992px и более) — три колонки в карточках, сайдбар справа от контента

Особенности реализации

  • ✅ Семантическая разметка: header, main, aside, footer, article, section, nav
  • ✅ БЭМ-именование классов
  • ✅ Адаптивная вёрстка (Mobile-First, 3 брейкпоинта)
  • ✅ Бургер-меню с JS-переключением
  • ✅ FAQ-аккордеон на нативном JS
  • ✅ Форма обратной связи с валидацией
  • ✅ Фильтрация сервисов по категории, цене и поиску
  • ✅ Таблицы сравнения с семантической разметкой
  • ✅ Видео через iframe (RuTube)
  • ✅ SVG-изображения для оптимизации
