# GameLearn — Обучение CSS, JS, HTML в игровой форме

[Live Demo](https://your-github-username.github.io/gamelearn/) | [Репозиторий](https://github.com/your-github-username/gamelearn)

## Описание

Тематический сайт-обзор сервисов для изучения CSS, JavaScript и HTML в игровой форме. Проект включает 10 связанных страниц с полной адаптивной вёрсткой, построенной на CSS-фреймворке Mustard UI.

## Технологии

- **HTML5** — семантическая и валидная разметка
- **CSS3** — кастомные стили поверх фреймворка (переменные, Flexbox, Grid, анимации)
- **Mustard UI** — CSS-фреймворк (mustard-ui.com)
- **JavaScript** — нативный JS (бургер-меню, FAQ-аккордеон, валидация форм, фильтрация)
- **БЭМ** — методология именования классов
- **Git / GitHub** — контроль версий и хостинг

## Структура проекта

- `index.html` — Главная страница
- `services.html` — Все сервисы (с фильтрами)
- `css-tracks.html` — CSS-треки
- `js-tracks.html` — JS-треки
- `html-tracks.html` — HTML-треки
- `compare.html` — Сравнение сервисов (таблицы)
- `examples.html` — Примеры мини-игр (скриншоты, видео)
- `faq.html` — Частые вопросы (аккордеон)
- `contact.html` — Контакты (форма обратной связи)
- `about.html` — О проекте
- `css/style.css` — Кастомные стили
- `js/main.js` — JavaScript
- `img/` — SVG-изображения

## Адаптивность

Mobile-First подход с 3 контрольными точками:
- Мобильные (< 768px)
- Планшеты (≥ 768px)
- Десктопы (≥ 992px)

1. Клонируйте репозиторий:
