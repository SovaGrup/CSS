HTML-треки

Платформы с игровыми элементами для изучения HTML5: семантика, формы, мультимедиа, доступность.

Платформы для изучения HTML

В отличие от CSS и JS, чисто игровых сервисов для HTML меньше. Однако крупные платформы используют геймификацию (бейджи, рейтинги, прогресс) для мотивации.

Codecademy: HTML

Интерактивный курс «Learn HTML» — бесплатно. Пишете код в браузере, получаете мгновенную обратную связь, зарабатываете бейджи.

HTMLFreemium

Что изучаете:

  • Структура HTML-документа
  • Семантические теги (header, main, nav, article)
  • Формы и input-элементы
  • Мультимедиа: img, video, audio

freeCodeCamp: HTML

Модуль «Responsive Web Design» — 300 часов бесплатно. Изучаете HTML и CSS через задания с проверкой, получаете сертификат.

HTMLCSSБесплатно

Что изучаете:

  • HTML-структура и семантика
  • Доступность (accessibility)
  • Адаптивная вёрстка
  • Практические проекты

Ключевые темы HTML5 для изучения

Тема Описание Где практиковать Сложность
Структура документа DOCTYPE, html, head, body, meta-теги Codecademy, freeCodeCamp Низкая
Семантические теги header, nav, main, article, section, aside, footer freeCodeCamp Низкая
Формы form, input, select, textarea, button, валидация Codecademy, freeCodeCamp Средняя
Мультимедиа img, video, audio, picture, source freeCodeCamp Средняя
Доступность (a11y) ARIA-атрибуты, alt, role, tabindex freeCodeCamp Высокая
