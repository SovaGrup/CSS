Рекомендации

  • ★ Для полного новичка: CSS Diner + Flexbox Froggy + freeCodeCamp (HTML-модуль).
  • ★ Для изучения CSS: CSS Diner → Flexbox Froggy → Grid Garden → CSS Battle.
  • ★ Для изучения JS: JSRobot → CodeCombat → Codewars (8 kyu) → CheckiO.
  • ★ Для сертификации: freeCodeCamp — единственный полностью бесплатный сервис с сертификатами.
  • ★ Для соревновательного духа: CSS Battle и Codewars — таблицы лидеров и рейтинги.
