CSS-треки

Игровые платформы для изучения CSS: селекторы, Flexbox, Grid, анимации и адаптивная вёрстка.

Игры по CSS

CSS Diner

32 уровня изучения CSS-селекторов. На каждом уровне нужно выбрать селектор, который выделит нужные элементы на «столе».

CSSБесплатно

Что изучаете:

  • Селекторы по тегу, классу, ID
  • Псевдоклассы (:nth-child, :first-of-type)
  • Комбинаторы (>, +, ~)
  • Универсальный селекторы и атрибуты

Flexbox Froggy

24 уровня. Перемещайте лягушку на кувшинку, используя Flexbox-свойства для выравнивания и распределения.

CSSБесплатно

Что изучаете:

  • justify-content, align-items
  • flex-direction, flex-wrap
  • align-self, order
  • flex-flow

Grid Garden

28 уровней изучения CSS Grid. Полейте морковку, располагая элементы через grid-свойства.

CSSБесплатно

Что изучаете:

  • grid-column-start / grid-column-end
  • grid-template-columns
  • grid-area, grid-row
  • repeat(), minmax(), fr-единицы

CSS Battle

Соревнования по вёрстке: воспроизведите заданный целевой дизайн с минимальным кодом. Таблица лидеров, рейтинг.

CSSFreemium

Что изучаете:

  • Позиционирование и раскладка
  • Градиенты, трансформы, clip-path
  • Оптимизация CSS-кода
  • Pixel-perfect вёрстка

Рекомендуемый порядок прохождения

  1. CSS Diner — основы селекторов. Займёт 30–60 минут.
  2. Flexbox Froggy — Flexbox-раскладка. 1–2 часа.
  3. Grid Garden — CSS Grid. 1–2 часа.
  4. CSS Battle — закрепление через соревнование. Регулярная практика.
«CSS Diner и Flexbox Froggy — это два сервиса, которые я рекомендую каждому новичку. За час вы получаете больше понимания, чем от трёх часов видео.» — Отзыв учащегося
